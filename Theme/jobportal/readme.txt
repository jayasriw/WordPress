Install Steps
--------------
Step 1: Go to Appearance > Add New Themes, then click Upload button

Step 2: Go to browse, then select the jobportal.zip file

Step 3: Click "Install Now" to install JobPortal

Step 4: Activate the newly installed JobPortal by going to Appearance > Themes, find JobPortal and click on "Activate" button

Step 5: Once JobPortal is activated, you will be redirected to JobPortal Welcome Screen. Switch to Plugins tab to install plugins.

Step 6: Click "Install" to begin installing plugins. After that, you will have to activate plugins.
